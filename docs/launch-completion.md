## Local services

The review server is `http://localhost:3000/`. Localhost does not have a 24-hour
expiry; it stops working when the process or machine stops. Restart with
`$env:NODE_USE_SYSTEM_CA='1'; pnpm dev` from this repository. Do not replace the
ignored environment or weaken live NFT ownership checks to cover RPC outages.

The verified scheduler is `scripts/local-monitor-scheduler.ts`, not an untested
cron file. It starts after 60 seconds, checks for due work every 15 minutes, and
approved alpha document sources use a minimum 24-hour cadence. It has an
exclusive process lock, bounded due batch, source timeouts and no email/Telegram
delivery. It reads the existing server-side environment and validates the target
project. Health: ignored `.local/monitor-scheduler.json` and `monitor-last-run.json`.
Start one hidden process with Node `--use-system-ca --import tsx
scripts/local-monitor-scheduler.ts`. Duplicate active instances are refused;
stale locks are removed only after the recorded process is absent.

Actual timer evidence: 2026-10-05T21:47:23Z checked one official alpha source and
saved `no_new_confirmed_event`; 22:02:26Z checked zero due sources and delivered
one deadline reminder. Windows Task Scheduler attempts did not produce a reliable
run and are not counted as working. There is no scheduler deployment or restart
guarantee across machine shutdown. The endpoint's separate CRON_SECRET remains
